# Task_01_Dua-Fatima

Project 1 – Data Cleaning & Preparation

Overview: <br>
This project was completed as part of my Data Analytics Internship. The objective was to clean and prepare a raw dataset to ensure data quality and consistency before further analysis.

Tools Used: <br>
- Microsoft Power BI (Power Query) <br>
- Dataset 

The dataset contains customer order information, including: <br>
- Order ID <br>
- Customer ID <br>
- Product <br>
- Quantity <br>
- Unit Price <br>
- Total Price <br>
- Payment Method <br>
- Order Status <br>
- Referral Source <br>
- Shipping Address <br>
- Tracking Information

Data Cleaning Tasks Performed: <br>
- Promoted headers. <br>
- Corrected data types for dates, numbers, and text. <br>
- Renamed columns for better consistency. <br>
- Replaced inconsistent values where required. <br>
- Removed duplicate records. <br>
- Removed blank rows. <br>
- Applied Trim to text fields to remove leading and trailing spaces. <br>
- Reordered columns for improved readability. <br>
-Verified that the dataset contains correctly formatted dates and no duplicate Order IDs.

Outcome: <br>
The dataset is now clean, consistent, and ready for data analysis and visualization.

- Data Cleaning. <br>
- Data Preparation. <br>
- Power Query. <br>
- Data Quality
